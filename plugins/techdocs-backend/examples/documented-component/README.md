# Example Docs (`documented-component`)

Built-in TechDocs sample used by the Backstage example app.

## Try document history

This site is configured with a GitHub `edit_uri`, so it works with the optional
Document History addon (commit history, tags, compare, blame, and revision
browsing).

See [Document History Demo](../../../../docs/features/techdocs/document-history-demo.md)
for step-by-step instructions. Quick start:

1. `cp app-config.local.yaml.example app-config.local.yaml`
2. `export GITHUB_TOKEN=...`
3. `yarn start`
4. Open `http://localhost:3000/docs/default/component/documented-component`
